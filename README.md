# Weather App

This is a simple weather app built with Python. It fetches weather data using the OpenWeatherMap API and displays it in a user-friendly GUI.

## Setup Instructions

1. Install Python (https://www.python.org/).
2. Install the `requests` library:
   ```
   pip install requests
   ```
3. Get an API key from [OpenWeatherMap](https://openweathermap.org/) and replace `"your_openweather_api_key"` in the script.

## How to Run

Navigate to the `src` folder and run the app:

```
python weather_app.py
```

Enjoy the weather updates!
